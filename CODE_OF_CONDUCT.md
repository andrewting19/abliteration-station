# Code of conduct

## Our standard

Be respectful, constructive, and specific. Welcome contributors with different
backgrounds and experience levels. Focus criticism on code, evidence, and user
impact. Do not harass, threaten, discriminate against, or publish private
information about another person.

## Project safety

Do not post credentials, private network addresses, prompts, transcripts,
account data, model weights, or provider runtime state. Report security issues
through GitHub private vulnerability reporting.

## Enforcement

Maintainers can edit or remove content and can temporarily or permanently ban
participation that violates this standard. Report conduct problems privately
through the repository security contact. Maintainers will review reports in
good faith and protect reporter privacy where practical.

## Scope

This standard applies in project spaces and when a person publicly represents
the project.
